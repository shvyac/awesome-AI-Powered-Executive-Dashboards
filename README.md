# awesome-AI-Powered-Executive-Dashboards

AIを活用した次世代の経営管理・組織変革に関するツール・サービス・記事を集めたAwesomeリストです。

## 概要

従来の静的な報告書とは異なり、AIは膨大なデータをリアルタイムで解析し、将来の業績予測や組織内の潜在的なリスクを精度高く特定します。具体的には、人的資本の可視化や不正の早期検知、さらにはデジタルツイン技術を用いた業務プロセスの最適化など、その活用範囲は多岐にわたります。こうしたツールは意思決定を迅速化させるだけでなく、データに基づいた客観的な判断を企業文化として定着させる役割も果たします。最終的に、AIダッシュボードは単なる管理ツールを超え、企業の持続的な成長を支える戦略的な基盤として位置付けられています。

## AIダッシュボード・BIプラットフォーム

エグゼクティブ向けに、自然言語での対話やAIによる自動インサイト生成を備えたダッシュボード・BIツール。

- [Omni Analytics](https://omni.co/) - ガバナンスされたセマンティックレイヤーとAI支援クエリを組み合わせた分析プラットフォーム。
- [ThoughtSpot](https://www.thoughtspot.com/) - 自然言語検索と自動インサイト生成を備えたカンバセーショナル分析。
- [Domo](https://www.domo.com/) - リアルタイムのデータ統合とAI機能を備えたダッシュボードツール。

## 人的資本の可視化（ピープルアナリティクス）

組織内の人材データを可視化し、採用・配置・離職リスクなどを分析するプラットフォーム。

- [Visier](https://www.visier.com/) - AIエージェントによる異常検知と人材計画のインサイトを提供するピープルアナリティクス基盤。
- [Workday](https://www.workday.com/) - クラウド型の人的資本管理（HCM）プラットフォーム。AIによる予測分析を統合。
- [ChartHop](https://www.charthop.com/) - 人員計画や組織デザインを支援するワークフォースアナリティクスツール。

## 不正の早期検知・異常検知

機械学習を用いて、取引データや行動ログから不正・異常を早期に検知する仕組み。

- [Fraud.net](https://www.fraud.net/) - AIによるリアルタイム不正検知プラットフォーム。
- [Sumsub Anomaly Detection](https://docs.sumsub.com/docs/ai-powered-anomaly-detection) - AIを活用した異常検知機能。
- [Anodot](https://www.anodot.com/) - 時系列データを対象としたAIによる異常検知ツール。

## デジタルツインによる業務プロセス最適化

業務プロセスをリアルタイムに可視化・シミュレーションし、ボトルネックの発見や最適化を行うプラットフォーム。

- [iGrafx Process360 Live](https://www.igrafx.com/) - 業務プロセスのデジタルツインを構築・管理するプラットフォーム。
- [Simio](https://www.simio.com/) - センサーやIoTデータと連携し、業務プロセスの「デジタルシャドウ」を継続的に更新するシミュレーションツール。
- [AVEVA Digital Twin](https://www.aveva.com/en/solutions/digital-transformation/digital-twin/) - エンジニアリング・オペレーション・経営データを統合する産業向けデジタルツイン。

## 業績予測・経営計画（FP&A）

AIを活用してリアルタイムに業績を予測し、経営判断を支援するプランニング・予測ツール。

- [Anaplan](https://www.anaplan.com/) - ML駆動の予測とシナリオ最適化を備えたエンタープライズ計画プラットフォーム。
- [Workday Adaptive Planning](https://www.workday.com/en-us/products/adaptive-planning/overview.html) - AIによる予測分析とシナリオプランニングを統合したクラウド型計画ツール。
- [Vena](https://www.venasolutions.com/) - Excelと連携したAI活用のFP&Aプラットフォーム。
- [IBM Planning Analytics](https://www.ibm.com/products/planning-analytics/ai-forecasting) - AIによる予測機能を備えた計画分析ツール。
